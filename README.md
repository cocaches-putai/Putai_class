# 普台高級中學 課表查詢系統

依班級／依教師查詢 115 學年度第一學期課表的純靜態網頁，單一 HTML 檔即可開啟（資料已內嵌在檔案裡），適合放在 GitHub Pages 上給全校師生查詢。

## 功能

- **依班級查詢**：選一個班級／分組代碼，看完整一週課表（非淨空週、淨空週分開顯示）
- **依教師查詢**：選一位老師，看完整一週課表
- 課表格子裡帶底線的老師姓名／班級代碼可以點擊直接跳轉查詢
- 支援淺色／深色主題（跟隨系統設定）
- 手機瀏覽可左右滑動看整週課表

## 資料來源與更新方式

資料來源為教務處「調代課配對小工具」裡的全校教師課表資料（115 位老師，國英數／自與社／藝能科三份課表合併）。本頁是從那份資料反推出班級視角、純粹拿來查詢用，**沒有調代課功能**。

之後學校課表異動、要更新這個頁面時，請直接跟 Claude 說「幫我把課表查詢系統更新到最新版」，Claude 會重新從「調代課配對小工具」抓最新資料、重新產生 `index.html`。不需要手動編輯資料。

## 已知限制

- 教室／座位查詢目前沒有做（目前的資料來源沒有教室欄位）
- 少數「分組選修代碼」（例如跑班、能力分組）的班級代碼不代表學生原本的班級，課表上會提示
- 若原始課表資料本身有誤（例如漏登打、未同步更新），這裡也會跟著顯示錯誤，請以教務處公告為準

## 部署到 GitHub Pages

1. 建立一個新的 GitHub repository（可以設公開或私有，公開才能用 GitHub Pages 的免費方案）
2. 把這個資料夾裡的 `index.html` 上傳到 repo 根目錄
3. 到 repo 的 **Settings → Pages**，Source 選 `Deploy from a branch`，Branch 選 `main` / `(root)`，儲存
4. 等 1-2 分鐘，GitHub 會給一個 `https://<帳號>.github.io/<repo名稱>/` 的網址，開啟就能看到課表查詢系統
